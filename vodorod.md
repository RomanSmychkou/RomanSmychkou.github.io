IB SYSTEM OBJECT (IBSO) – универсальная автоматизированная банковская система (АБС) для банков любого масштаба бизнеса. Программный комплекс полностью отвечает высоким стандартам современного банковского бизнеса и успешно эксплуатируется в крупнейших финансовых организациях стран СНГ и Беларуси. Это надежный фундамент для цифровизации банковских процессов.
IBSO обеспечивает поддержку банковского бизнеса по ключевым направлениям:

Клиентское обслуживание корпоративных и частных клиентов;
Операции банка на финансовом и фондовом рынках;
Бухгалтерский учет и отчетность;
Административно-хозяйственная деятельность банка;
Корпоративное управление.
Специалисты IBSO Developer получают следующие возможности:

развитие экспертизы по одной из самых востребованных АБС систем на рынке;
приобретение опыта FullStack разработки на языке PL/PLUS (язык основан на PL/SQL и Java), включая: разработку экранных форм операций и логики их взаимодействия с пользователем; создание процедур, функций и представлений для обработки различных банковских транзакций;
опыт разработки интеграционных решений с использованием подходов REST API, форматов json/xml и брокеров сообщений (MQ);
углубленные навыки работы с Oracle Database (SQL, PL/SQL) на уровне, необходимом для банковской разработки.
Наши ожидания от кандидатов:

базовые знания PL/SQL (или других языков программирования);
знания основ SQL: умение создавать и управлять таблицами (CREATE, ALTER, DROP) и работать с данными (INSERT, SELECT, UPDATE, DELETE);
понимание основ REST API и принципов обмена данными между системами;
понимание основ реляционных баз данных, включая: связи между таблицами: знание типов связей (один-к-одному, один-ко-многим, многие-ко-многим) и их реализации с помощью первичных и внешних ключей; виды соединений (JOIN): опыт написания запросов с использованием различных видов соединений (INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN) для объединения данных из нескольких таблиц на основе связей между ними;
знание английского языка (на уровне, необходимом для изучения технической документации).
